# 框架边界与迁移清单

> 适用：本地 `0.1.0-SNAPSHOT`。公共能力已实现并可独立构建，尚未发布稳定版。业务内容始终由扩展 JAR 提供。

## 公共能力

| 能力 | 框架实现 | 扩展 JAR 提供 |
|---|---|---|
| 主屏与入口 | `WorkspaceScreen`、功能目录搜索／分页、固定入口、窗口栏 | 功能声明、窗口工厂、业务对象 ID |
| 窗口 | 单例／按对象实例、置顶、拖动、拖动／文本尺寸调整、最小化／恢复动画、固定 HUD、scope 清理 | 窗口内容、业务会话生命周期 |
| 网格库存 | `InventorySnapshot`、`InventoryState`、`InventoryDelta`、占格预检、跨窗拖放、旋转、分堆 | 权威快照、服务端移动／分堆事务 |
| 装备与自定义落点 | `ItemSlotComponent`、`ItemDropTarget`、`InventoryDragSession` | 槽位 ID、布局、物品来源、接受条件、装备请求 |
| 物品展示 | 图标与缺失回退、数量、主题边框、`ItemPresentation` 提示／操作 | 稀有度映射、属性行、详情窗、菜单动作 |
| 通用显示组件 | `StatusBarComponent`、`EffectStripComponent` | 属性含义、单位、效果标签／时长和列表 |
| 模型预览 | `ModelPreviewComponent` 自动适配、水平／俯仰旋转、自动旋转、聚焦过渡、缩放、裁剪 | 模型包围盒、几何／纹理／渲染器，或玩家实体适配 |
| HUD 与底栏 | 注册、同源投影、锚点、显隐、拖动、缩放、复位 | HUD 数据及绘制、栏位内容、绑定／清除请求 |
| 外观 | 灰绿渐变主题、颜色令牌、背景注册、本地图片／缩略图、资源重载及回退 | 自定义调色板、背景资源 |
| SVG | 注册资源、受限安全解析、三角网格、染色与重载缓存 | SVG 图形与业务 HUD 布局 |
| 本地偏好 | 版本化 JSON、原子替换、坏文件保护、缺失模块记录保留 | 无需自行保存框架表现设置 |
| 通信 | `UiWire`、`UiProtocolSession`、Fabric 通道、协商、路由、结果、超时、连接隔离 | 每种消息的载荷 schema、编解码及处理器、服务器实现 |

## 边界规则

框架不内置装备部位枚举、技能栏容量、职业／种族限制、身体拓扑、属性公式、制作配方、战利品会话或物品资产。动作名称、能否使用／装备以及服务器权限校验也属于扩展。

模型画布不是业务模型库。它接收一个 `Model` 渲染器，所有模型数据与资源由子 JAR 持有。状态条和效果条同样只展示投影，不根据名称推断玩法。

工作台不自动加载某个库存或装备子屏。没有子 JAR 时，框架仍有目录、HUD 管理和外观入口；目录内容由已安装模块决定。启动缺少必需模块会明确报错，服务器向未安装模块发送事件会得到 `MODULE_MISSING`。

`src/demo/` 只用于独立示例 JAR。模拟库存事务、示例物品、演示窗口及模型不进入框架运行 JAR。主框架与示例分别构建，不要求用户安装示例。

## 窗口偏好

默认路径为 Fabric 配置目录下的 `kizuna-inventory-ui.json`，格式版本为 `WorkspacePreferences.FORMAT_VERSION`。保存主题、背景、按窗口类型的期望外框、HUD 布局、固定功能入口、窗口类型固定偏好和动画开关；不保存服务器对象 ID、库存内容或连接身份。

明确关窗、拖动／调整尺寸完成、离开工作台和断线时保存。扩展程序通过 API 批量调整表现后可调用 `runtime.savePreferences()`。坏文件或更高版本文件会记录错误并保留原文件，当前运行使用默认外观，写回被拒绝。可通过 `runtime.preferenceError()` 查询。

尺寸和位置按窗口类型记忆；不会在重新连接时自动重开交易、制作或对象会话。窗口的实际外框随视口裁切，期望尺寸保留供大视口恢复。外观菜单可重置窗口布局。

## 验证范围

本地 Java 17 单测覆盖库存／增量／拖动边界、布局文件兼容和 wire 编解码往返；真实 Minecraft 客户端 smoke 验证跨窗口移动、分堆守恒、底栏绑定、模型和通用组件绘制。网络协议除内存契约测试外，已通过独立 Fabric 服务端与客户端的实际通道往返验收；生产服务器业务接入、多端联机与完整兼容矩阵仍由接入项目单独验收。
