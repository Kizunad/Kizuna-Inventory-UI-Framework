# 公共通信协议

适用：未发布的 `0.1.0-SNAPSHOT`、Framework wire v2。协议唯一来源为 `src/main/proto/kizuna/inventoryui/v2/`，生成 Java 类不提交。

框架提供 `kizuna_inventory_ui:message` 通道、连接协商、类型化消息路由和请求回执。服务端入口在交付业务模块前检查协议版本、模块归属、消息方向、请求身份、载荷大小和解析深度；玩家上下文来自宿主认证连接。

客户端提交业务意图，逻辑服务器负责业务验证并发布权威状态。单机使用内置服务器，复用同一套服务端路由。框架不定义特定容器、重量规则或业务持久化格式，这些属于各业务模组自己的 `.proto` 和服务端实现。

完整信封字段、状态同步及迁移说明见[服务器通信](Server-Communication.md)；服务端模块注册和验证边界见[服务端模块](Server-Modules.md)。
